# Historical source and assessments

Accompanying Markdown files preserve text outputs and refer to extracted PNG figures. These files retain the historical bugs, Colab paths, and stateful execution order for provenance; run `esdl` commands instead.

`reviews/` contains the two pre-cleanup review documents unchanged. Their statements about absent parameters, proposed notebook retention, or release scope are historical and superseded by the supplied assets, the current request, and the main README.

The original notebook files were removed only after their source exports and outputs were checked. No `.ipynb` file is needed or retained in this project.
